    Operator guide

    OrbINT

    Open-source Reconnaissance Bureau of Intelligence

    OrbINT is for collecting, organizing, analyzing, and managing information gathered through reconnaissance of publicly available sources. It also works as case and investigative management software. The workspace is local, not cloud-based: cases stay on this device, with no remote account and no cloud data-breach risk.

    Local by design

    There is no OrbINT cloud and no sign-in. Profiles, photos, the timeline, and the whiteboard live in this browser. That is why the desk is safe to work from: a remote breach cannot take a copy that was never sent. Export a case file when you need a backup. Clear site data and the case leaves with it.

    Start a case

    Work one person, company, or asset at a time. Begin with the strongest identifier you already have — usually a name, username, email, or phone — then let that fact open the next search.

    1
    Type into a pill The value files as you type. You do not need to press Enter. Empty the box and the fact drops off.
    Name → Jordan HaleEmail → jhale@pm.me
    2
    Watch the hub A filled pill turns green. Marking a field Missing turns it red. The ring around OrbINT fills green for values and red for missing. Clearing a box lowers the ring immediately.
    3
    Read the casebook On desktop the left sheet is the case file. On a phone, open Casebook. It shows the subject name, filed facts by group, and a rail of saved profiles. Click a row to focus that field. Under + Add information, Last updated shows when this site last changed on GitHub.

    Search the right way

    Every pill has an action on the right. That is the intended next step — not guessing random sites.

    1
    Empty field — information The i icon lists where that kind of fact usually turns up. Use this when you do not have the value yet.
    Phone empty → Whitepages, TruePeopleSearch
    2
    Filled field — magnifier The search icon opens deeper lookups with the value already in the URL, and copies it for sites that need a paste. Image search uses the photo, not the file name.
    domain.com → WHOIS, crt.sh, Wayback
    OrbINT is a local investigative desk: identity, accounts, infrastructure, vehicles and registration, credentials, records, media, chronology, and boards. File the fact, then search from the pill. The dock Toolkit holds the broader OSINT catalog when you need a source that is not on the pill. Nothing is uploaded to a cloud.

    Special fields

    Username Choose the platform first, then enter the handle. The icon stays on the pill. Instagram → @jordanh
    Image / Audio Paste a URL, or use + to upload. Preview opens from the thumbnail. https://…/portrait.jpg
    IP Geolocation, hosting, and indexed services. The pin opens a map when the address looks valid. 8.8.8.8
    Timezone Pick PST, EST, or another common zone. The pill shows the abbreviation and a live clock — not the city name. EST · Eastern Time
    Company Employer, workplace, or legal name. Search opens filings, EDGAR, ownership, and sanctions lists. Northwind Analytics LLC
    VIN / Plate Decode, history, registration, and owner trails. MAC, Geo, and Barcode live under Add a field. 1HGCM82633A004352

    Move around the map

    The orbit is the workspace. Zoom and pan as far as you want — there is no limit. Recenter puts the default view back.

    Scroll Zoom Pinch Zoom Drag empty space Pan Middle-drag Pan Drag hub Move orbit

    The + on the hub adds a field. Pick a hidden or extra one, or type a name to create your own. Right-click a field (long-press on a phone) to copy, cut, paste, rename, clear, search, or remove that pill. Right-click empty map space to drop a linked profile where you clicked, or for Help, Recenter, Undo, Redo, Export, Share, and Reset. Right-click the center circle to link this case to other profiles. Linked subjects appear on the map — phone and desktop — with a line between them. Tap a linked circle to open that case. Recenter restores the default view. Drag the right edge of the left sheet to resize the casebook. Reset wipes every profile, the map, and saved layout, then hard-refreshes so the latest site loads.

    Profiles

    Keep more than one subject. The rail on the left of the casebook is the case shelf. Linked profiles also sit on the orbit as extra circles.

    SwitchClick a face to open that profile. The orbit and facts follow it.
    NewThe rail plus starts a separate blank case. Right-click empty map space to drop a linked circle where you clicked. No name needed — file it when you have one.
    LinkRight-click the hub to connect this case to another profile. A cyan mark on the rail face means this case has a linked subject. A line stays between them on the map.
    UploadImport an OrbINT .json profile, including files from Export.
    RenameThe pencil names the current profile. Right-click a face to rename, duplicate, download, or delete.

    Investigation pages

    The titles at the top of the workspace switch the orbit for other case views. The casebook stays put. The dock follows the page.

    OrbINTThe orbit workspace. File identifiers around the subject.
    TimelineA pan-and-zoom chronology. Click the axis to add an event. Type on a card, attach an image, drag the card to place it. Minimize tucks the extra fields. Connect cards draws a grey arrow between them. Recenter fits the axis.
    WhiteboardA canvas in OrbINT’s dark UI. Use the Selection tool and drag to select several shapes. Toolbar: lock, shapes, draw, text, image, eraser, connect, pre-sets. Drag to size a shape. The image tool makes a frame you fill. Paste an image anytime. Connect shapes shows every point. Ctrl+Z undoes.
    Case FileA print preview of the case record, laid out like the PDF.

    A clean first pass

    Name + city, then username, then email or phone. Use the i icon or magnifier before adding a weaker identifier. Example: file Jordan Hale, search people directories, pick up @jordanh on Instagram, then check whether that handle repeats on WhatsMyName.

    Esc closes menus, previews, and this guide.
