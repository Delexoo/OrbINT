Operator guide

OrbINT

Open-source Reconnaissance Bureau of Intelligence

OrbINT is for collecting, organizing, analyzing, and managing information gathered through reconnaissance of publicly available sources. It also works as case and investigative management software. The workspace is local, not cloud-based: cases stay on this device, with no remote account and no cloud data-breach risk.

Local by design

There is no OrbINT cloud and no sign-in. Profiles, photos, the timeline, the whiteboard, notes, and harvested files live in this browser. A remote breach cannot take a copy that was never sent. Export a case file when you need a backup. Clear site data and the case leaves with it.

The titles across the top switch the workspace. Operator guide in the dock opens this page. On a phone it is labeled Guide. Casebook is an extra title in that bar.

Operations

The opening desk. A street map from OpenStreetMap, drawn by OpenFreeMap, plus security news and a few local tools. Scroll to zoom into a city. Attacks, outages, and cameras sit on top of the map.

AttacksOne dot per attacking address, on that address’s city coordinates. Live and Day each take the day’s top 1,000 from SANS plus the 30-day source list. Week merges the last seven daily lists. Month, Year, and Decade stay inside that 30-day public feed. Hover a dot for the matching story’s headline and image, or the country flag, plus the address. Click the dot to open that article. If no story matches, the click opens the SANS source for that address.
OutagesThe same map, drawn from IODA. The time buttons change the outage window. Alerts for countries, regions, and networks are placed on the country they name. Several alerts in one country spread apart so each stays visible. Click a dot to open that outage record.

Timeline

A pan-and-zoom chronology for the open case. Click the axis to add an event. Type on a card, attach an image, and drag the card to place it. Minimize tucks the extra fields. Connect cards draws an arrow between them. Recenter fits the axis.

Events with a date, time, title, or note are written into the case file. An empty timeline adds no section.

Whiteboard

A canvas in the same dark desk. Use the Selection tool and drag to select several shapes. The toolbar has lock, shapes, draw, text, image, eraser, connect, and presets. Drag to size a shape. The image tool makes a frame you fill. Paste an image anytime. Connect shows every point. Ctrl+Z undoes.

A card is filed when it has a title or text. Empty shapes, default labels, and bare drawings are left out. Links between filed cards are included. If the board has nothing to say, the case file skips it.

Notepad

Short notes kept with this case. New note starts a blank page. The title and the body save as you type. Hold Shift and click notes to link them. On a phone, tap Link, then another note. The graph shows those links. Drag the dividers to resize the list and the graph.

A note is filed when it has a title or text. An untitled empty note is not. Links between filed notes are included. An empty notepad adds no section to the case file.

Harvester

Drop in a messy file. OrbINT keeps names, dates, accounts, phones, passwords, addresses, and other identifiers, and sets the rest aside. Split shows the original beside the stripped text. Original and Stripped are the other views. Upload, start a new file, copy, or download as text, Markdown, JSON, HTML, CSV, or XML.

Only extracted values are written into the case file. A file that yields nothing does not add a section.

Case file

The printable record of the open case. The sheets on screen are the same pages as the PDF. Sensitive values stay covered until you reveal them. The downloaded file contains the full record.

Case captionCase number, offense, status, investigator, subject, and the date of the record.
ParticularsFiled facts from the orbit, in a stable order, with confidence, method, and source when you set them.
TimelineAdded only when the chronology has an event.
WhiteboardAdded only when a card has a title or text.
NotepadAdded only when a note has a title or text.
HarvesterAdded only when a file produced a value.
PhotographsAdded only when the case has a picture beyond the portrait.
NotesFiled notes, analysis, and evidence notes. Empty notes are omitted.

Download PDF in the dock writes that record. Section numbers follow whatever is actually present, so a blank page never leaves a blank heading.

Share

Share sends one encrypted link for the open case. Turn Live session on and the link can be viewed, and only while you keep the session on. End it and the link shows nothing. The key stays after #. The server stores ciphertext, not the case.

Copy link puts that session URL on the clipboard. The code underneath is for the public site, https://orbint.net/, and Share site hands the page to the system share sheet when the device has one.

File the fact, then search from the pill. Use the pages to keep chronology, diagrams, notes, and extracted text with the same case. The case file prints only the pages that have something in them.

Esc closes menus and sheets. It leaves this page open. Switch titles to go back to the case.

Questions

Where does a case live?

On this device, in this browser. There is no OrbINT account and no remote case database.

Who operates OrbINT?

Delexoo. Reach them at github.com/Delexoo. Privacy, terms, and contact are in Settings.

Does a search leave the computer?

Only the value you send, and only to the public service you open. The rest of the case stays here.

How do I keep a copy?

Export JSON from the dock. Upload JSON on the profile rail puts that file back. The browser does not keep an automatic backup.
