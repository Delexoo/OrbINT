Operator guide

How OrbINT is meant to be used

One subject. File every fact you have on the orbit — people, accounts, infrastructure, vehicles, records, media — then search outward from each field. The left sheet is the case file.

Start a case

Work one person, company, or asset at a time. Begin with the strongest identifier you already have — usually a name, username, email, or phone — then let that fact open the next search.

1
Type into a pill The value files as you type. You do not need to press Enter. Empty the box and the fact drops off.
Name → Jordan HaleEmail → jhale@pm.me
2
Watch the hub A filled pill turns green. The ring around OrbINT fills as more fields have values. Clearing a box lowers the ring immediately.
3
Read the portfolio The left sheet shows the subject name, a short ID line, and filed facts by group. The rail on its left holds saved profiles. Click a row to focus that field. Hover a row to remove it.

Search the right way

Every pill has an action on the right. That is the intended next step — not guessing random sites.

1
Empty field — information The i icon lists where that kind of fact usually turns up. Use this when you do not have the value yet.
Phone empty → Whitepages, TruePeopleSearch
2
Filled field — magnifier The search icon opens deeper lookups with the value already in the URL, and copies it for sites that need a paste. Image search uses the photo, not the file name.
domain.com → WHOIS, crt.sh, Wayback
OrbINT is the full workstation: identity, accounts, infrastructure, vehicles and registration, credentials, records, media, and anything you add. File the fact, then search from the pill.

Special fields

Username Choose the platform first, then enter the handle. The icon stays on the pill. Instagram → @jordanh
Image / Audio Paste a URL, or use + to upload. Preview opens from the thumbnail. https://…/portrait.jpg
IP Geolocation, hosting, and indexed services. The pin opens a map when the address looks valid. 8.8.8.8
Timezone Pick PST, EST, or another common zone. The pill shows the abbreviation and a live clock — not the city name. EST · Eastern Time
Work Employer, workplace, or legal name. Search opens filings, EDGAR, ownership, and sanctions lists. Northwind Analytics LLC
VIN / Plate Decode, history, registration, and owner trails. MAC, Geo, and Barcode live under Add a field. 1HGCM82633A004352

Move around the map

The orbit is the workspace. Keep the subject in view; do not treat pan and zoom as part of the case file.

Scroll Zoom Middle-drag Pan Drag hub Move orbit

The + on the hub adds a field. Pick a hidden or extra one, or type a name to create your own. Right-click a field to copy, cut, paste, rename, clear, search, or remove that pill from the orbit. Right-click empty map space for Help, Recenter, Undo, Redo, Export, Share, and Reset. Recenter restores the default view. Drag the right edge of the left sheet to resize the portfolio. Reset wipes every profile, the map, and saved layout, then reloads a fresh page.

A clean first pass

Name + city, then username, then email or phone. Use the i icon or magnifier before adding a weaker identifier. Example: file Jordan Hale, search people directories, pick up @jordanh on Instagram, then check whether that handle repeats on WhatsMyName.
