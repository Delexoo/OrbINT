# OrbINT

A circular OSINT case-file tool. Each fact you enter — phone, name, email, username, address, and the rest — is added to a subject profile with public next-search links.

## Open it

- Live: https://delexoo.github.io/OrbINT/
- Or open `index.html` in a browser

## Analyze profile

Copy `.env.example` to `.env` if you run a local helper later, or create `config.js` from `config.example.js` and add an OpenRouter key. Do not commit `config.js` or `.env`.

## What this is not

OrbINT is for public-source research only. It does not include password collection or illegal plate-to-owner lookups.
